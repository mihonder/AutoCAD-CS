# AutoCAD-CS

Локальный Counter-Strike по мотивам CS 1.6 в поле модели AutoCAD.
Dust 2, команды 5×5 с ботами, покупка оружия, стрельба и раунды.
Карта изображена белыми контурами и штриховками на чёрном фоне.
Боты нарисованы в чёрно-белом стиле чертежа и анимированы слайдами.
Оружие в руках отображается цветными слайдами.

**[Скачать готовый compat24 для AutoCAD 2020–2027](https://github.com/mihonder/AutoCAD-CS/releases/tag/compat24)**

Автор — **mihonder**. Текущая игровая сборка — **compat24 от 2 ноября 2026 года**.

## Быстрый запуск

1. Откройте страницу релиза по ссылке выше и скачайте
   **`CS16-by-mihonder-compat24-AutoCAD2020-2027.zip`** из раздела **Assets**.
2. Распакуйте архив в любую папку. Путь может содержать пробелы.
3. Откройте отдельный пустой чертёж в AutoCAD и введите **`_APPLOAD`**.
4. Выберите **`CS16.lsp`** из корня распакованного архива, нажмите
   «Загрузить», затем «Закрыть».
5. В командной строке введите **`CS16`** и нажмите Enter.
6. Игра откроется на паузе. Нажмите **F6**, чтобы включить управление.

`CS16` пишется слитно, без точки. APPLOAD регистрирует эту команду.
Игра запускается после её ввода. Загрузчик сам выбирает модуль для версии AutoCAD.

Для игры достаточно готового архива и установленного AutoCAD.
Файл `CS16.lsp` самодостаточен, игровые DLL и ресурсы находятся внутри него.
При первом запуске подходящий модуль извлекается в
`%LOCALAPPDATA%\CS16\portable\compat24-<hash>\`.
Подробная инструкция есть в `README.txt` внутри архива.

## Совместимость

Для полного AutoCAD на Windows x64 подготовлены четыре модуля.

| AutoCAD | Среда модуля | API |
| --- | --- | --- |
| 2020 | .NET Framework 4.7 | 23.1 |
| 2021–2024 | .NET Framework 4.8 | 24.0 |
| 2025–2026 | .NET 8 | 25.0 |
| 2027 | .NET 10 | 26.0 |

Все четыре модуля компилируются с соответствующими SDK Autodesk.
Игровая логика проверяется автономно на .NET Framework, .NET 8 и .NET 10.
Переносимый запуск и управление внутри AutoCAD 2025 проверялись в compat21.
Для compat24 выполнены автономные проверки. Проверки этой сборки внутри
всех перечисленных версий AutoCAD ещё предстоят.

AutoCAD LT, macOS и Windows x86 находятся вне текущего охвата проекта.
Для AutoCAD 2013–2019 загрузчик выводит сообщение о минимальной версии 2020.
Для новых поколений API после 2027 потребуется обновлённый пакет.
Шрифт интерфейса — ISOCPEUR из установки AutoCAD.

## Управление

| Клавиши | Действие |
| --- | --- |
| F6 | Захватить или освободить управление |
| Esc | Назад в меню или пауза |
| Удержание Esc | Освободить управление |
| WASD, Shift | Бег, шаг |
| Ctrl, Space | Присесть, прыгнуть |
| ЛКМ, ПКМ | Стрелять, оптика при наличии |
| 1 / 2 / 3, колесо | Выбрать оружие |
| B / И, затем цифры | Купить оружие |
| R | Перезарядить |
| G, E | Бросить, подобрать оружие |
| H / Р | Сложность ботов |
| M / Ь | Выбрать T или CT, боты уравняют команды |
| Tab | Таблица счёта |
| F5 | Новый раунд |
| После смерти короткий Space | Переключить наблюдение |
| После смерти удержание Space 1,2 с | Перезапустить раунд |

Раунд длится до пяти минут после трёхсекундной подготовки.
В игре 22 профиля огнестрельного оружия с упрощёнными отдачей и разбросом.
Слот 4 зарезервирован под гранаты.

Чтобы завершить игру и восстановить вид чертежа, освободите управление
клавишей F6 и введите **`DUSTSTOP`**. Команда **`CS16`** начинает новую игру.

## Постоянная установка и удаление

Для автоматической регистрации команды при запуске AutoCAD скопируйте
папку `CS16.bundle` из архива целиком в
`%APPDATA%\Autodesk\ApplicationPlugins\` и перезапустите AutoCAD.

Ручной `NETLOAD` также доступен. Модули и их зависимости расположены в
`CS16.bundle/Contents/<семейство AutoCAD>/`. Сохраняйте соседние DLL вместе.

Для удаления закройте AutoCAD, удалите добавленный `CS16.bundle` или
переносимый `CS16.lsp`. Кэш конкретной сборки можно удалить из
`%LOCALAPPDATA%\CS16\portable\`. Диагностические журналы находятся в
`%LOCALAPPDATA%\CS16\logs\compat24\`.

## Сборка исходников

Понадобятся Windows x64, .NET SDK 10, .NET 8 Desktop Runtime, .NET Framework 4.8
и Python 3. Зависимости и SDK AutoCAD загружаются из NuGet.
Готовые игровые ресурсы включены в репозиторий.

В PowerShell из папки проекта выполните

```powershell
.\build-compat.ps1
```

Путь к отдельной установке .NET 10 можно передать параметром

```powershell
.\build-compat.ps1 -DotNet "C:\Tools\dotnet10\dotnet.exe"
```

Скрипт собирает четыре модуля, запускает игровые проверки на трёх средах,
проверяет очередь кадров, создаёт переносимый файл запуска и ZIP.
Результат находится в `dist/CS16-by-mihonder-compat24-AutoCAD2020-2027.zip`.
Для повторной упаковки собранных модулей используйте `package-compat.ps1`.

| Файлы | Назначение |
| --- | --- |
| `CadDustLab.csproj`, `*.cs` | Игровая логика, отрисовка, ввод и адаптер AutoCAD |
| `scene.json`, `*.json.gz`, `*-vectors.json`, `wall-lettering.json` | Геометрия и подготовленные ресурсы |
| `distribution/` | Загрузчики, описание bundle и инструкция |
| `preview/`, `checks/` | Автономные проверки |
| `build-compat.ps1`, `package-compat.ps1`, `make_portable.py` | Сборка и упаковка |

При подготовке репозитория скрипт сборки получил настраиваемый путь к SDK,
тест отдачи создаёт папку для своего отчёта, а эталоны поз оружия хранятся
в тестовых данных репозитория для запуска проверок из свежего клона.
Архив опубликован из сохранённой сборки compat24. Его SHA-256 приложен к релизу.

Сведения об исходных игровых материалах и сторонних библиотеках находятся
в [THIRD-PARTY.txt](THIRD-PARTY.txt).
