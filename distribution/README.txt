CS 1.6 — версия 1.1.0
AutoCAD 2020–2027, Windows x64. Автор: mihonder.

ЗАПУСК
1. Распакуйте архив в любую папку. Пробелы в пути допустимы.
2. В отдельном пустом чертеже AutoCAD введите _APPLOAD.
3. Выберите CS16.lsp, нажмите «Загрузить», затем «Закрыть».
4. Введите CS16 и нажмите Enter.
5. Игра откроется на паузе. F6 включает управление.

CS16.lsp содержит игровые модули и ресурсы.
Подходящая версия выбирается автоматически.

УПРАВЛЕНИЕ
F6 — захватить или освободить управление.
Esc — назад в меню или пауза. Удержание Esc — освободить управление.
WASD — бег; Shift — шаг; Ctrl — присесть; Space — прыгнуть.
ЛКМ — огонь; ПКМ — оптика, если есть.
1/2/3, колесо — выбрать оружие.
B/И — покупка, затем цифры. R — перезарядка.
G — бросить оружие; E — подобрать.
H/Р — сложность ботов. M/Ь — команда, боты уравняются.
L/Д — язык. 1 — русский (при запуске), 2 — English.
Press F6 to play, then L and 2 for English.
Tab — счёт. F5 — новый раунд.
После смерти: короткий Space — сменить наблюдение;
удержание Space 1,2 с — перезапустить раунд.
Чтобы закрыть игру и восстановить вид чертежа:
освободите управление клавишей F6, затем введите DUSTSTOP.

СОВМЕСТИМОСТЬ
Полный AutoCAD на Windows x64:
2020 — .NET Framework 4.7;
2021–2024 — .NET Framework 4.8;
2025–2026 — .NET 8;
2027 — .NET 10.
AutoCAD LT, macOS и Windows x86 не поддерживаются.

Все четыре модуля проходят сборку и автономные проверки.
Работу внутри каждой версии AutoCAD нужно проверять отдельно.

ДРУГИЕ СПОСОБЫ УСТАНОВКИ
Для постоянного подключения скопируйте CS16.bundle целиком в
%APPDATA%\Autodesk\ApplicationPlugins\ и перезапустите AutoCAD.
Для NETLOAD выберите AutoCADCS.dll из подпапки нужной версии в
CS16.bundle\Contents\. Сохраняйте соседние DLL вместе.

УДАЛЕНИЕ
Закройте AutoCAD и удалите добавленный CS16.bundle или CS16.lsp.
Кэш этой версии: %LOCALAPPDATA%\CS16\portable\v1.1.0-...\.
Журналы: %LOCALAPPDATA%\CS16\logs\v1.1.0\.
