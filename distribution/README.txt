CS16 by mihonder — compat24

Полный AutoCAD 2020–2027 для Windows x64. Не AutoCAD LT и не macOS.
Игра работает в поле модели: белые контуры и штриховки на чёрном фоне.

ПРОСТОЙ ЗАПУСК ИЗ ЛЮБОЙ ПАПКИ
1. Распакуйте архив в удобную папку.
2. В отдельном пустом чертеже AutoCAD введите _APPLOAD.
3. Выберите CS16.lsp в корне распакованного архива, нажмите «Загрузить»,
   затем «Закрыть». Появится сообщение «CS16 loaded. Type CS16 to start the game».
   На этом этапе только зарегистрирована команда; игра ещё не запущена.
4. Введите CS16 (без пробелов и точки) и нажмите Enter. Игра сама определит
   версию AutoCAD и откроется на паузе. Первая подготовка модуля может занять
   несколько секунд. Выбирать DLL вручную не нужно.
5. F6 включает управление игрой. Повторный F6 освобождает управление.
6. Для новой игры в этом чертеже снова используйте команду CS16.

CS16.lsp самодостаточен: подходящие DLL и ресурсы вложены в этот файл.
Нужный модуль извлекается в %LOCALAPPDATA%\CS16\portable\compat24-...\.
Каталог игры может содержать пробелы; установка в папки Autodesk не нужна.
Загрузчик использует штатные Windows MSXML6 и ADO, без внешних программ.

АЛЬТЕРНАТИВЫ
Для постоянного подключения поместите CS16.bundle целиком в
%APPDATA%\Autodesk\ApplicationPlugins\, перезапустите AutoCAD и введите CS16.
NETLOAD также работает: выберите CadDustCompat24.dll из подходящей подпапки
CS16.bundle\Contents\, сохраняя соседние зависимости. При простом запуске
через APPLOAD выбирать версию вручную не требуется.

Это локальная сборка без цифровой подписи. Если AutoCAD запрашивает доверие
к загружаемому модулю, решение принимает пользователь/администратор.
Защитные настройки загрузчик не меняет. В организациях установку выполняют
по принятой политике доверенных приложений. Альтернативное место установки:
%PROGRAMFILES%\Autodesk\ApplicationPlugins (требует прав администратора).

МОДУЛИ
2020: .NET Framework 4.7, API 23.1.
2021–2024: .NET Framework 4.8, API 24.0.
2025–2026: .NET 8, API 25.0.
2027: .NET 10, API 26.0.
Все DLL зависимостей поставляются рядом с соответствующим модулем.
Системные DLL Autodesk в архив не включены, их предоставляет сам AutoCAD.
Карты, оружие и слайды уже встроены. Python, SDK и интернет для игры не нужны.
Не перемещайте отдельную DLL без соседних файлов, особенно в 2020–2024.
Используйте Windows, поддерживаемую вашей версией AutoCAD; отдельной
зависимости игры от конкретной редакции Windows нет. Нужна x64.
Для будущих версий после 2027 потребуется обновлённый пакет.
В AutoCAD 2013–2019 команда сообщает о минимальной версии 2020.

СТАТУС ПРОВЕРКИ
Все четыре сборки проверяются компилятором с официальными SDK Autodesk.
Игровые тесты выполняются на .NET Framework, .NET 8 и .NET 10.
В compat21 в AutoCAD 2025 проверялись переносимый запуск из одной LSP и ввод.
Compat24 проверена автономно, без запуска AutoCAD: очередь кадров, игровой ввод,
раунды, здоровье, отдача/разброс, приседание на 136 склонах и выпадение оружия
при смерти сидя. Исправления требуют проверки в настоящей игре.
2020–2024, 2026, 2027 требуют пробного запуска на соответствующем AutoCAD;
сборка с SDK сама по себе не подтверждает работу графики и перехвата на нём.

Ввод принимается отдельным потоком, без очереди нажатий AutoCAD.
Устаревшие действия отбрасываются, клики не накапливают будущие выстрелы.
Курсор скрывается через обработку окна модели и восстанавливается при выходе.
В compat22 устранена зависимость кадров от низкоприоритетного WM_TIMER:
одновременно ожидает максимум один запрос кадра. Накопления кадров нет.
Подготовка раунда: мигающие 3–2–1 и убывающая полоска. Во время подготовки
можно осматриваться и покупать; движение и стрельба доступны после отсчёта.
Начальная пауза отдельно подписана: F6 — войти в игру.

ЗДОРОВЬЕ И УРОН
У бота 100 HP в начале каждого раунда. Базовый урон пистолетов приведён к CS 1.6:
Glock 25, USP 34, P228 32, Desert Eagle 54, Dual Elites 36, Five-Seven 20.
Модель попаданий упрощена: корпус ×1, верхняя зона фигуры ×2,5. Отдельные зоны
конечностей, броня ботов и ослабление пули с расстоянием не моделируются.
Это не полная копия баллистики CS. По свежему боту Glock требует 4 попадания
в корпус или 2 в верхнюю зону. Одна пуля Desert Eagle в верхнюю зону смертельна.
Любой пистолет может добить бота, которого уже ранили другие участники боя.

НОВОЕ В COMPAT24
Исправлены приседание на склонах и вылет при выпадении оружия после смерти сидя.
Добавлены умеренные аркадные отдача и разброс всех огнестрельных видов оружия:
очередь поднимает прицел и расширяет разброс, пауза восстанавливает точность;
приседание улучшает точность, движение и прыжок ухудшают. Параметры зависят
от оружия, оптика повышает точность. Это приближение, не точная баллистика CS 1.6.
Лимит раунда — 5 минут после подготовки. Уничтожение команды завершает его раньше.

УПРАВЛЕНИЕ
CS16 — новая игра. Игра запускается на паузе.
F6 — войти/выйти из захвата. Esc — меню назад либо пауза.
Удержать Esc — освободить управление.
WASD — бег; Shift — шаг; Ctrl — присесть; Space — прыжок.
ЛКМ — огонь; ПКМ — оптика, если есть.
1/2/3, колёсико — оружие. 4 — пустой слот гранат.
B/И — покупка, затем цифры. R — перезарядка. G — бросить, E — подобрать.
H/Р — сложность ботов. M/Ь — команда: 1 T, 2 CT; боты уравниваются 5×5.
Tab — счёт. F5 — новый раунд.
После смерти: короткий Space меняет режим наблюдения; удержание 1,2 с
перезапускает раунд. ЛКМ/ПКМ переключают наблюдаемого бота.
F6, затем DUSTSTOP — закрыть игру и восстановить вид чертежа.

УДАЛЕНИЕ/ОТКАТ
Закройте AutoCAD и уберите CS16.bundle из ApplicationPlugins.
При переносимом запуске удалите CS16.lsp; после закрытия AutoCAD можно удалить
кэш %LOCALAPPDATA%\CS16\portable\compat24-...\. Журналы лежат отдельно в
%LOCALAPPDATA%\CS16\logs\compat24\. Предыдущие compat23, compat22, compat21 и compat20 сохранены.
Новая сборка не изменяет DWG-геометрию карты: игра рисуется временной графикой.
